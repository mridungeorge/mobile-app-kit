# __APP_NAME__ — Native iOS Starter (Swift + SwiftUI)

A minimal, buildable SwiftUI project generated by **Mobile App Factory**.

- Language: Swift
- UI: SwiftUI (App lifecycle, `NavigationStack`)
- Project: [XcodeGen](https://github.com/yonaskolb/XcodeGen) `project.yml` (no fragile `.pbxproj` checked in)
- Deployment target: iOS 17 (raise only if you drop older devices deliberately)
- Bundle id: `__BUNDLE_ID__`

## Run it (macOS)

```bash
brew install xcodegen
xcodegen generate
open __PROJECT_NAME__.xcodeproj
```

Select a simulator and press Run. Open the project in **Xcode** for signing,
capabilities, Archive, and TestFlight.

> No Mac? You can still author the Swift sources and keep the pipeline artifacts;
> building and submitting requires Xcode on macOS or a macOS CI runner.

## Where things live

```
Sources/App.swift                       @main entry point
Sources/ContentView.swift               root view / navigation
Sources/DesignSystem/Theme.swift        Rune tokens -> SwiftUI colors and type
Sources/Screens/HomeScreen.swift        first screen
Resources/PrivacyInfo.xcprivacy         privacy manifest starter (edit to match SDKs)
Resources/Assets.xcassets/              app icon + accent colour slots
Tests/                                  XCTest starter
```

Design tokens come from the skill and are pre-mapped in
`Theme.swift`. Keep to the Rune rules: neutral surfaces, one accent, hairline borders
instead of large shadows, 4/8/12/16/24 spacing.

## Release checklist (short)

1. Set your Team, bundle id, and capabilities in Xcode.
2. Add a real 1024×1024 app icon and accent colour.
3. Complete `PrivacyInfo.xcprivacy` to match the SDKs actually linked.
4. Add purpose strings for every permission you request.
5. Archive → upload to App Store Connect → TestFlight.
6. Fill in App Privacy, age rating (5-tier), DSA trader status (EU), and review notes.

Full guidance: the native iOS release and App Store guides in this project's `docs/` folder.
