# __APP_NAME__ — Native Android Starter (Kotlin + Jetpack Compose)

A minimal, buildable Android Studio/Gradle project generated by **Mobile App Factory**.

- Language: Kotlin
- UI: Jetpack Compose + Material 3
- Build: Gradle Kotlin DSL + version catalog
- `compileSdk` / `targetSdk`: 36 (re-verify Play requirements at submission)
- `minSdk`: 26

## Run it

```bash
# Build + install a debug build (Gradle wrapper included; needs only a JDK 17)
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

Or open this folder in **Android Studio** and press Run.

> Version numbers in `gradle/libs.versions.toml` are starter values. Android Studio will offer
> upgrades; take them before your first release build.

## Where things live

```

app/src/main/java/__PACKAGE_PATH__/ui/App.kt              root composable
app/src/main/java/__PACKAGE_PATH__/ui/screens/            screens
app/src/main/java/__PACKAGE_PATH__/ui/theme/              design tokens -> Material 3
app/src/main/res/values/strings.xml                       copy
```

Design tokens come from the skill and are pre-mapped in
`ui/theme/Color.kt` and `ui/theme/Type.kt`. Keep to the Rune rules: neutral surfaces,
one accent, hairline borders instead of large shadows, 4/8/12/16/24 spacing.

## Release checklist (short)

1. Create an upload keystore and `keystore.properties` (see `android-templates/`).
2. Enable Play App Signing in Play Console.
3. Set `versionCode` / `versionName` for every upload.
4. Run `./gradlew lint test` and `./gradlew :app:bundleRelease` (AAB).
5. Complete the Play data-safety form to match the SDKs actually shipped.
6. Start the closed test track early — new personal accounts need **12 testers for
   14 continuous days** before production access.

Full guidance: the native Android release checklist in this project's `docs/` folder.
