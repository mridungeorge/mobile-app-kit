Approval checklist

Decision

Feedback stays in this file until you run the review command. Nothing is uploaded.

How to close the loop

  1. Fill the checklist, choose Approve or Request changes, add notes.
  2. Click Download feedback.json and save it to .mobile/preview/feedback.json.
  3. Run:

node scripts/review-preview.mjs --dir .mobile --from-feedback .mobile/preview/feedback.json

Changes are applied to the intake and profile, and a new preview is generated for re-approval. Approval writes .mobile/00-approval.json and unlocks Phase 1.

What this preview is

An illustrative approval-stage preview of structure, flow and tone — not the final production UI. Final screens are implemented in the selected native stack with real data, states, accessibility and motion.

Still external: developer accounts, signing keys/certificates, CI secrets, backend/services, real-device testing, store submission and review.

Concept/architecture diagrams are a different job: Anatomy can draw interactive explanatory figures; it does not replace app UI previews.
