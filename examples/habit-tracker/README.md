# Habit Tracker — the factory's end-to-end example

One idea, run through the whole pipeline: intake → profile → preview → approval → PRD → design →
build → motion → compliance → release → review. Everything here was generated by the skills in this
repository; nothing is hand-tuned outside them except the two documented gaps below.

## What is in the box

| Path | What it is |
|---|---|
| `.mobile/` | the factory artifacts: profile, PRD, design, build log, motion, compliance, release, review, metadata, preview |
| `android/` | Kotlin + Jetpack Compose project, scaffolded by `scaffold-native.mjs` |
| `ios/` | Swift + SwiftUI project (XcodeGen), scaffolded by the same script |
| `ci.yml` | the commands the root CI jobs run |

## Run it

```bash
cd examples/habit-tracker/android && ./gradlew :app:assembleDebug
# macOS:
cd examples/habit-tracker/ios && xcodegen generate && xcodebuild -scheme HabitTracker \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

## What was automated vs human

| Phase | Automated | Human still needed |
|---|---|---|
| Intake / profile / preview | `questionnaire.mjs`, `route-idea.mjs`, `generate-preview.mjs`, `review-preview.mjs --approve` | approve the preview (done here as the sample user) |
| PRD / design / motion / compliance / release | agent wrote the `.mobile/` files; `lint-artifacts.mjs` and `validate-metadata.mjs` check them | review copy and declarations |
| Build | `scaffold-native.mjs`; CI compiles and tests both projects | signing keys, store accounts, real devices |
| Screenshots | CI steps capture simulator/emulator screenshots as artifacts | commit them under `screenshots/` after a CI run |
| Submission | checklist in `06-release.md` | upload, TestFlight, 12-tester gate, rollout |

## Timing (this run)

| Step | Wall clock |
|---|---|
| intake + route + preview + approval | under 1 minute |
| agent-written artifacts (phases 1–7) | ~15 minutes |
| scaffolding both native projects | under 1 minute |
| **total to a buildable, reviewed plan** | **~17 minutes** |

Build time is CI's, not measured here.

## Honest gaps

`07-review.md` is a **FAIL**: the History screen and the purchase path are specified but not
implemented, and the example declares `restrained` motion without a device test. Screenshots have
not been produced because this machine has no emulator or Xcode; the CI jobs upload them as
artifacts but do not commit them. Fix the two blockers before treating this as a submission-ready
app — the point of the example is that the pipeline surfaces them instead of hiding them.
